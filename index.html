01 / REAL-TIME SYSTEM

Watch Party

A web app where everyone in a room watches the same video in lock-step, with live chat, reactions, polls and a shared queue.

Goal
Keep every viewer's playback in sync, including late joiners and people who reconnect.
How it works
The server holds the playback clock and every action carries a sequence number. Clients drop anything older than what they have applied, so conflicting actions converge on the same state. A client-side loop detects drift and corrects it.
Engineering notes
One runtime dependency (ws) and no build step. Typo-tolerant search uses Damerau–Levenshtein distance. Tests cover the protocol, concurrency, reconnects and the sync algorithm.
  • Node.js
  • WebSockets
  • JavaScript
  • YouTube IFrame API

02 / FULL-STACK · DJANGO

E-Clinic

An online clinic where patients find doctors, book video or in-clinic appointments and receive digital prescriptions.

What it does
Separate sign-up flows and role-based dashboards for patients and doctors. A doctor directory with search and speciality filters. Slots generated from each doctor's working hours. Confirming a video appointment generates a Jitsi Meet link, and prescriptions can be printed or saved as PDF.
Engineering notes
Booked, past and double-booked slots are excluded, and a database constraint enforces the double-booking rule too. Appointments move through pending → confirmed → completed, with cancellation and rejection paths. The repo includes tests and a seeded demo.
  • Django
  • Python
  • Bootstrap 5
  • SQLite
  • Jitsi Meet
  • Vercel

03 / FULL-STACK · SIMULATION

TWIN

A personal-finance “digital twin” that lets you ask what could happen before you commit to a loan, an investment or a car.

What it does
An onboarding wizard builds a financial profile. You then pick a scenario (loan, invest or car), adjust it and see projected outcomes on an animated chart, with a history of earlier runs.
Architecture
A FastAPI backend with auth, profile, scenario, simulate and history routers, backed by SQLAlchemy. The simulation package is split into an engine, Monte Carlo runs, scenario effects and sensitivity analysis. The React frontend draws the forecast as an animated SVG line.
  • FastAPI

  • SQLAlchemy

04 / FULL-STACK · MERN

Evermore

A personalised wedding planner: each couple gets an account and private data for their guest list, budget, checklist and vendors.

What it does
A dashboard with a days-until-the-wedding countdown. A guest list with RSVP status, meal preference and plus-ones, and an automatic head count. A budget tracker comparing estimated and actual cost against the overall budget. A checklist that flags overdue tasks, and a vendor tracker.
Architecture
Express and Mongoose API with JWT authentication. React frontend with React Router, Axios and context-based auth.
